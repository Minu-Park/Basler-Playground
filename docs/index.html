Script Editor

C++ on the live frame.
Tuned with a slider.

Write a script against the current frame and build it. Mark a variable with @interactive and the loaded build adds it to Interactive Parameters — move it while the camera keeps grabbing.

  • WriteNative C++ with clangd. Use get() for the frame and show() for the result.
  • Build & loadThe script compiles to a native library and swaps into the pipeline without stopping acquisition.
  • Tunelevel appears under Interactive Parameters. Keep scrolling — or drag it yourself.

External libraries

Bring the code you already trust.

Register any C++ library — your in-house vision code or a vendor SDK — with its include, library and runtime DLL paths and the libraries to link. Then #include it in a script.

  • One list of librariesOpen Libraries from the main status bar, next to the loaded library count.
  • Headers, link files, DLLsPoint to .h / .hpp folders, .lib folders and files, and the .dll folder used at run time.
  • Checked before the buildPaths and link files are resolved when you apply, so a missing library shows up here — not as a build error.
